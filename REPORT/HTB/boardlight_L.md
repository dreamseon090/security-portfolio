## RECON
**nmap**: 초기 정찰을 통해 어떤 포트가 열려 있는지 확인하기 위해 전체 포트 검사와 상세 검사를 진행했다.
```bash
nmap -p- -T4 IP
```
```bash
nmap -sC -sV -p 22,80 IP
```
```bash
sudo nmap -sUV --top-ports 100 IP
```
포트 검사를 통해 HTTP 서비스와 SSH 서비스가 열려 있다는 것을 알게 되었다. 따라서 웹사이트 FUZZING을 진행했다.


## New Inform
- MySQL에서 그냥 출력을 하면 보기 어렵기 때문에 \G 옵션을 사용하여 세로 형태로 출력한다.
- 항상 Credential Reuse를 생각하자. 무조건 크랙을 해야 한다는 고정관념을 버리자.
- 항상 SUID는 bin과 같은 곳에 있다는 고정관념을 버리자.
- dpkg -l로 프로그램들의 버전을 확인할 수 있다.
- 항상 lib든 뭐든 여러 가지 있으면 의심하자.
- **CVE-2022-37706**: Enlightenment(리눅스 데스크톱 환경)의 SUID root 바이너리 enlightenment_sys에서 발생하는 로컬 권한 상승. 입력 검증 미흡 때문에 mount 기능에 명령어 주입이 가능해서 일반 유저가 root 쉘을 얻을 수 있다.
